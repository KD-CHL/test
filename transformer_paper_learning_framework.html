矩阵乘法与形状

01§1 Introduction · §2 Background第 1–2 页

动机：为什么要抛弃 RNN？

2017 年以前，机器翻译的主流是「RNN 编码器–解码器 + 注意力」。这一节要搞清楚 RNN 慢在哪里、卷积方案差在哪里，以及 Transformer 换来了什么、付出了什么。

约 20 分钟入门关键词：顺序计算 · 并行 · 路径长度

学习目标

  • 说清 RNN 为什么难以并行训练
  • 理解「关联两个位置需要多少步操作」这个衡量标准
  • 知道 Transformer 的取舍：路径变短了，代价是什么、怎么补救

1.1RNN 的瓶颈：只能一步一步算

循环神经网络沿着序列逐个位置计算隐状态：

第 t 步的隐状态 ht 依赖上一步的 ht−1 和当前输入 xt

这种「天生顺序」的结构排除了样本内部的并行计算：不算完第 t−1 步，就没法算第 t 步。序列越长问题越严重，而显存又限制了跨样本的批量大小。论文提到，分解技巧（factorization tricks）和条件计算（conditional computation）等改进虽然显著提升了效率，但顺序计算这个根本约束依然存在。

1.2三种方案对比：x₁ 的信息怎样传到 x₆？

衡量一个结构「学远距离依赖」难不难，可以看两个位置之间的信号要走多少步。路径越短，梯度越容易传过去。

RNN：顺序递推

O(n) 步

x₁ 要经过 5 次递推才到 h₆，而且这 5 步必须按顺序算，无法并行。

卷积：逐层扩大视野

O(n/k) 层

卷积核 k=3 时要堆 3 层，x₁ 和 x₆ 才能「碰面」。ConvS2S 的步数随距离线性增长；ByteNet 用空洞卷积，降到 O(logk n)。

自注意力：一步直达

O(1) 步

每个位置直接和所有位置相连，任意两个词之间都只隔一层，而且所有位置可以同时计算。

模型与计算方式关联两位置的操作数层内并行
RNN / LSTM沿时间步递推O(n)，随距离线性增长否
ConvS2S堆叠卷积随距离线性增长是
ByteNet堆叠空洞卷积随距离对数增长是
Transformer自注意力常数 O(1)是
!
取舍：路径短了，分辨率会变低注意力的输出是对各位置的加权平均，平均会「抹平」细节，降低有效分辨率。论文用多头注意力来抵消这个问题（见模块 04）。

1.3自注意力并不是新概念

自注意力（self-attention，也叫 intra-attention）指把同一个序列中不同位置关联起来，以计算这个序列的表示。它此前已用于阅读理解、摘要生成、文本蕴含和学习句子表示等任务；端到端记忆网络则用了基于注意力的循环机制。

论文的关键说法是：据作者所知，Transformer 是第一个完全依赖自注意力来计算输入和输出表示、不使用按序列对齐的 RNN 或卷积的转导（transduction）模型。

×
常见误区「Transformer 发明了注意力机制。」—— 不对。注意力早就用在 RNN 翻译模型里了（如 Bahdanau 等人 2014 年的工作）。本文的创新是只用注意力，把循环和卷积彻底去掉。

Q1RNN 训练难以并行的根本原因是什么？

ht 依赖 ht−1，同一个序列里的各时间步只能顺序计算；序列一长，显存又限制了跨样本的批量大小。

Q2ConvS2S、ByteNet 这类卷积模型相比 RNN 好在哪，又差在哪？

好在同一层所有位置可以并行计算；差在关联两个远距离位置需要的操作数随距离增长（ConvS2S 线性、ByteNet 对数），远距离依赖更难学。

Q3自注意力把路径长度降到常数，代价是什么？怎么弥补？

加权平均会降低有效分辨率；论文用多头注意力来抵消。

2.1编码器–解码器框架

多数有竞争力的序列转导模型都是编码器–解码器结构：编码器把输入符号序列 (x1, …, xn) 映射成连续表示 z = (z1, …, zn)；解码器根据 z 每次生成一个符号，得到输出 (y1, …, ym)。每一步都是自回归的：生成下一个符号时，把已经生成的符号当作额外输入。

2.3编码器和解码器各有几层、几个子层？

编码器 · N = 6 层

每层 2 个子层：

  1. 多头自注意力
  2. 逐位置全连接前馈网络

每个子层外都有残差连接，接着做层归一化。

解码器 · N = 6 层

每层 3 个子层：

  1. 掩码多头自注意力（不能看后面的位置）
  2. 对编码器输出的多头注意力
  3. 逐位置全连接前馈网络

同样每个子层都有残差 + 层归一化。

为了方便做残差连接，模型中所有子层和嵌入层的输出维度都是 dmodel = 512。

2.5Add & Norm：每个子层外面的包装

Sublayer(x) 是子层本身（注意力或 FFN）。先把子层输出和输入 x 相加（残差连接），再做层归一化。训练时子层输出在相加之前还会经过 dropout（模块 07）。

这种「先相加、后归一化」的写法后来被称为 Post-LN。很多后续实现改成 Pre-LN，即 x + Sublayer(LayerNorm(x))，训练更稳定。这属于后续工作，不是本文内容。

2.6输出右移一位 + 掩码 = 自回归

解码器的自注意力经过修改，不允许某个位置关注它后面的位置。这个掩码，再加上「输出嵌入右移一位」，保证了位置 i 的预测只依赖于位置小于 i 的已知输出。以把 “I love you” 翻译成德语为例：

位置1234
解码器输入（右移后）<s>Ichliebedich
要预测的输出（标签）Ichliebedich</s>

<s> 表示句子开始，</s> 表示句子结束。位置 2 的输入是 “Ich”，它要预测 “liebe”，只能看到 <s> 和 Ich。

×
常见误区「Transformer 生成时也是并行的。」—— 只对了一半。训练时完整的目标句是已知的，配合掩码，解码器所有位置可以并行计算；推理时仍然是自回归的，必须一个词一个词地生成。

Q1编码器每层有几个子层？解码器呢？分别是什么？

编码器 2 个：多头自注意力、FFN。解码器 3 个：掩码多头自注意力、编码器–解码器注意力、FFN。

Q3「输出右移一位」和「掩码」分别解决什么问题？

右移让位置 i 的输入是第 i−1 个词，用它来预测第 i 个词；掩码阻止位置 i 看到后面的词。两者结合，保证位置 i 的预测只依赖于已知的前文。

3.1注意力到底在做什么

论文的定义：注意力函数把一个查询（query）和一组键–值对（key-value）映射成一个输出，query、key、value 和输出都是向量。输出是 value 的加权和，每个 value 的权重由 query 和对应 key 的兼容性函数（compatibility function）算出。

Query 查询

你想找什么

当前这个词发出的「提问」：我需要哪些信息？

Key 键

每本书的标签

每个词对外展示的「索引」，用来和 query 比较匹配程度。

Value 值

书里的内容

匹配之后真正被取走、被加权混合的信息。

✓
图书馆类比普通检索只把最匹配的那一本书给你；注意力是「软检索」：按匹配程度给每本书分配权重（加起来等于 1），把所有书的内容按权重混合成答案。

3.2公式 (1) 与 5 个计算步骤

  1. 1MatMul：打分

    Q 乘以 KT，得到每个 query 对每个 key 的匹配分数。

  2. 2Scale：缩放

    所有分数除以 √dk，防止数值过大（见 3.4）。

  3. 3Mask：掩码（可选）

    解码器里把「未来位置」的分数设为 −∞（见模块 04）。

  4. 4SoftMax：归一化

    对每一行做 softmax，变成和为 1 的权重。

  5. 5MatMul：加权求和

    权重乘以 V，得到每个 query 的输出。

(1)
Q：n × dk　K：m × dk　V：m × dv　→　QKT：n × m　→　输出：n × dv

实际计算时，把一组 query 打包成矩阵 Q，key 和 value 打包成矩阵 K、V，一次矩阵运算就能同时算出所有位置的输出。这就是 Transformer 能高度并行的原因。

3.5两种常见注意力：加性 vs 点积

加性注意力（additive）

用一个单隐层的前馈网络来计算兼容性函数。理论复杂度和点积注意力相近。

点积注意力（dot-product）

和本文算法相同，只差缩放因子 1/√dk。可以用高度优化的矩阵乘法实现，实践中更快、更省显存。

dk 较小时两者表现相近；dk 较大时，不缩放的点积注意力不如加性注意力。缩放因子正是为了解决这个问题。

4.1思路：投影 h 次、并行算注意力、再拼接

用不同的、可学习的线性投影，把 query、key、value 分别投影 h 次，变成 dk、dk、dv 维；在每个投影版本上并行执行注意力，得到 h 个 dv 维的输出；把它们拼接起来，再做一次投影，得到最终结果。

4.2注意力在模型里的三种用法

① 编码器自注意力

Q、K、V 全部来自编码器上一层的输出。编码器中每个位置都能关注上一层的所有位置。

② 解码器掩码自注意力

每个位置只能关注截至自己（含自己）的位置。为保持自回归性质，在缩放点积注意力内部，把非法连接对应的 softmax 输入设为 −∞。

③ 编码器–解码器注意力

Q 来自解码器上一层，K、V 来自编码器的输出。解码器每个位置都能关注输入序列的所有位置，模仿了经典 seq2seq 模型的注意力。

6.3互动：自注意力什么时候更省？

自注意力每层是 O(n²·d)，循环层是 O(n·d²)，两者之比为 n/d。所以当序列长度 n 小于表示维度 d 时，自注意力层更快。机器翻译中最先进的模型使用 word-piece 或 byte-pair 表示，句子长度通常远小于 512，这个条件大多能满足。

6.4卷积与受限注意力

  • 单个卷积层（核宽 k < n）连不通所有输入输出位置对：连续卷积核要堆 O(n/k) 层，空洞卷积要 O(logk(n)) 层，这会拉长任意两个位置之间的最长路径。卷积层的计算量通常也比循环层多 k 倍。
  • 可分离卷积能把复杂度大幅降到 O(k·n·d + n·d²)。但即使 k = n，它的复杂度也只是等于「自注意力层 + 逐点前馈层」的组合，而这正是 Transformer 的做法。
  • 面对非常长的序列，可以把自注意力限制在以输出位置为中心、大小为 r 的邻域里：复杂度降到 O(r·n·d)，代价是最大路径长度增加到 O(n/r)。作者计划在未来研究这个方向。
+

8.3推理设置

  • 检查点平均：base 模型取最后 5 个检查点的平均（每 10 分钟保存一次），big 模型取最后 20 个。

9.3局限与思考 延伸思考

O(n²) 的代价

计算量和显存随序列长度平方增长，长序列很贵。§4 已经提出受限注意力作为方向。

推理仍是自回归

训练可以并行，生成时仍要逐词进行。这也是作者把「生成不那么依赖顺序」列为目标的原因。

点积未必最优

外推能力未验证

正弦位置编码「可能外推到更长序列」只是一个假设，文中没有实验支持。

A.4PyTorch 代码骨架

教学用骨架，对应论文的公式 (1)–(3)。省略了 padding 掩码、批处理和训练循环，可以作为第三遍「复现」的起点。

transformer_core.py
import math
import torch
import torch.nn as nn
import torch.nn.functional as F


def attention(q, k, v, mask=None):
    """缩放点积注意力，公式 (1)"""
    d_k = q.size(-1)
    scores = q @ k.transpose(-2, -1) / math.sqrt(d_k)      # (..., n, n)
    if mask is not None:
        scores = scores.masked_fill(~mask, float("-inf"))   # 不允许看的位置设为 -inf
    weights = F.softmax(scores, dim=-1)                     # 每行权重和为 1
    return weights @ v, weights


class MultiHeadAttention(nn.Module):
    """多头注意力：h=8 个头，每个头 d_k = d_v = 512 / 8 = 64"""
    def __init__(self, d_model=512, h=8):
        super().__init__()
        assert d_model % h == 0
        self.h, self.d_k = h, d_model // h
        self.w_q = nn.Linear(d_model, d_model, bias=False)  # 8 个 W_i^Q 拼成一个矩阵
        self.w_k = nn.Linear(d_model, d_model, bias=False)
        self.w_v = nn.Linear(d_model, d_model, bias=False)
        self.w_o = nn.Linear(d_model, d_model, bias=False)  # W^O

    def forward(self, x_q, x_kv, mask=None):
        b, n, _ = x_q.shape

        def split(t):  # (b, len, 512) -> (b, 8, len, 64)
            return t.view(b, -1, self.h, self.d_k).transpose(1, 2)

        q, k, v = split(self.w_q(x_q)), split(self.w_k(x_kv)), split(self.w_v(x_kv))
        out, _ = attention(q, k, v, mask)
        out = out.transpose(1, 2).reshape(b, n, self.h * self.d_k)  # Concat
        return self.w_o(out)


class PositionwiseFFN(nn.Module):
    """逐位置前馈网络，公式 (2)：512 -> 2048 -> 512"""
    def __init__(self, d_model=512, d_ff=2048):
        super().__init__()
        self.lin1 = nn.Linear(d_model, d_ff)
        self.lin2 = nn.Linear(d_ff, d_model)

    def forward(self, x):
        return self.lin2(F.relu(self.lin1(x)))


def positional_encoding(n, d_model=512):
    """正弦位置编码（3.5 节）"""
    pos = torch.arange(n).unsqueeze(1).float()               # (n, 1)
    i2 = torch.arange(0, d_model, 2).float()                  # 2i = 0, 2, 4, ...
    angle = pos / torch.pow(10000.0, i2 / d_model)            # (n, d_model/2)
    pe = torch.zeros(n, d_model)
    pe[:, 0::2] = torch.sin(angle)                            # 偶数维用 sin
    pe[:, 1::2] = torch.cos(angle)                            # 奇数维用 cos
    return pe


def causal_mask(n):
    """解码器掩码：位置 i 只能看 0..i（True = 允许）"""
    return torch.tril(torch.ones(n, n, dtype=torch.bool))


class EncoderLayer(nn.Module):
    """自注意力 + FFN，每个子层：LayerNorm(x + Dropout(Sublayer(x)))"""
    def __init__(self, d_model=512, h=8, d_ff=2048, p=0.1):
        super().__init__()
        self.attn = MultiHeadAttention(d_model, h)
        self.ffn = PositionwiseFFN(d_model, d_ff)
        self.norm1, self.norm2 = nn.LayerNorm(d_model), nn.LayerNorm(d_model)
        self.drop = nn.Dropout(p)

    def forward(self, x, src_mask=None):
        x = self.norm1(x + self.drop(self.attn(x, x, src_mask)))
        return self.norm2(x + self.drop(self.ffn(x)))


class DecoderLayer(nn.Module):
    """掩码自注意力 + 编码器-解码器注意力 + FFN"""
    def __init__(self, d_model=512, h=8, d_ff=2048, p=0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, h)
        self.cross_attn = MultiHeadAttention(d_model, h)
        self.ffn = PositionwiseFFN(d_model, d_ff)
        self.norms = nn.ModuleList([nn.LayerNorm(d_model) for _ in range(3)])
        self.drop = nn.Dropout(p)

    def forward(self, y, memory, tgt_mask, src_mask=None):
        y = self.norms[0](y + self.drop(self.self_attn(y, y, tgt_mask)))
        # Q 来自解码器，K、V 来自编码器输出 memory
        y = self.norms[1](y + self.drop(self.cross_attn(y, memory, src_mask)))
        return self.norms[2](y + self.drop(self.ffn(y)))


class Transformer(nn.Module):
    """6 层编码器 + 6 层解码器（base 模型）"""
    def __init__(self, vocab, d_model=512, N=6, h=8, d_ff=2048, p=0.1, max_len=1024):
        super().__init__()
        self.emb = nn.Embedding(vocab, d_model)
        self.scale = math.sqrt(d_model)                       # 嵌入乘以 sqrt(d_model)
        self.register_buffer("pe", positional_encoding(max_len, d_model))
        self.enc = nn.ModuleList([EncoderLayer(d_model, h, d_ff, p) for _ in range(N)])
        self.dec = nn.ModuleList([DecoderLayer(d_model, h, d_ff, p) for _ in range(N)])
        self.drop = nn.Dropout(p)
        self.out = nn.Linear(d_model, vocab, bias=False)
        self.out.weight = self.emb.weight                     # 嵌入层与输出层共享权重

    def embed(self, tokens):
        return self.drop(self.emb(tokens) * self.scale + self.pe[: tokens.size(1)])

    def forward(self, src, tgt, src_mask=None):
        x = self.embed(src)
        for layer in self.enc:
            x = layer(x, src_mask)
        tgt_mask = causal_mask(tgt.size(1)).to(tgt.device)
        y = self.embed(tgt)
        for layer in self.dec:
            y = layer(y, x, tgt_mask, src_mask)
        return self.out(y)                                    # softmax 交给损失函数


def lrate(step, d_model=512, warmup=4000):
    """学习率调度，公式 (3)"""
    step = max(step, 1)
    return d_model ** -0.5 * min(step ** -0.5, step * warmup ** -1.5)
